# 压力数据

三场比赛共 39 题，每题固定 12 个压力文件和 3 个 trick 文件。种子由比赛 ID 和题号的 SHA-256 决定；文件使用确定性的 gzip 压缩，扩展名为 `.bin`，避免静态服务器自动解压影响下载校验。

`stress_*.py` 生成大数据，`fast-oracles.cpp` 计算大规模参考答案。`liaoning.py`、`online1.py` 和 `online2.py` 提供独立的小规模穷举或模拟，用于 `verify-stress.py` 的交叉验证。构造题允许任何满足要求的答案，浮点题采用原题的误差规则。

验证分三层：

1. `verify-stress.py`：穷举子集、排列、游戏状态、折叠和边的取舍；直接模拟树上任务、字符串操作和前缀；对照几何最远点穷举。检查所有加速参考程序，以及计数公式和贪心。
2. `validate-constraints.py`：逐文件解析输入，检查范围、多测总量、树结构、排列、字符串、操作合法性和凸多边形方向，输出实际覆盖范围 `src/data/stress-report.json`。
3. `validate-tests.mjs`：核对压缩数据 SHA-256 和字节数，用网站的独立校验器检查构造答案和交互协议。浏览器测试另行执行大输入、大输出、三种 C++ 标准和真实 PyPy3。

主要压力族包括百万元素、三百万字符、五十万点深链、十八层满树、百万计数输出、2000×2000 矩阵、严格凸多边形、大整数边界、重复约束和位查询边界。规模由原题约束决定；固定小输入题通过边界组合覆盖，构造题还包含大量多测。例如第一场 E 当前最大单组为 512，最大文件包含 10000 组、5120000 个输出元素，具体数值见覆盖报告。

这些文件是公开自测数据，覆盖结构族与边界，不能替代命题组完整隐藏数据。

参考核对使用命题组发布的 [辽宁省赛官方题解](https://codeforces.com/gym/106380/attachments/download/36003/%E9%A2%98%E8%A7%A3%20-%20%E7%AC%AC%E5%85%AD%E5%B1%8A%E8%BE%BD%E5%AE%81%E7%9C%81%E5%A4%A7%E5%AD%A6%E7%94%9F%E7%A8%8B%E5%BA%8F%E8%AE%BE%E8%AE%A1%E7%AB%9E%E8%B5%9B%EF%BC%88%E6%B2%88%E9%98%B3%EF%BC%89.pdf) 和 [2026 网络赛第二场官方题解](https://codeforces.com/gym/106701/attachments/download/39422/sol.pdf)。参考程序为本项目实现，小规模验证程序与加速算法独立。
