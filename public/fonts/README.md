# Fonts

Text uses **LXGW WenKai (霞鹜文楷)**, the font used by the
[Phycat theme](https://github.com/sumruler/typora-theme-phycat).

The code font can be selected independently in workspace settings:

- [Cascadia Code](https://github.com/microsoft/cascadia-code)
- [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono)
- [Fira Code](https://github.com/tonsky/FiraCode)
- The operating system's default monospace font

Web fonts are bundled from the pinned Fontsource dependencies during the build
and served by Testing OJ itself. Visitors do not need to install fonts or connect
to a font CDN. Full SIL Open Font License notices are included in this directory.
